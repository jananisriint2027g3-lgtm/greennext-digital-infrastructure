# Green Data reference audit

Reviewed locally extracted reference files from `Green Data.zip`:

- `index.html` — asset clusters, proposed hubs, solution themes and strategic claims.
- `locations.html` — location-specific portfolio descriptions and site claims.
- `infrastructure.html` — conceptual infrastructure layers and technical reference targets.
- `solutions.html` — proposed built-to-suit, powered-shell and industrial solution themes.
- `V2-GreenNext-Technologies.html` — Coimbatore/Madurai portfolio and EOI language.

## Content treatment

The supplied HTML is treated as reference material, not as independent verification. Acreage, land title, substation distance or capacity, fibre routes, approvals, construction readiness, investment, customer, PUE/WUE and operating-facility claims are therefore not presented as verified GreenNext facts in the updated regional pages.

Regional pages expose an evidence label and source note. Trichy and Madurai/Coimbatore reference developments are marked `Under Validation`; Mangalore remains `Not Confirmed` because no city-specific development claim was used from the supplied reference. All regional pages retain the existing conceptual-network disclaimer.
